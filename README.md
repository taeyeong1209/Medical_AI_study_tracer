# Medical AI Trend Tracer

의료·생명공학 데이터 기반 AI 연구 동향을 매주 자동으로 조사·큐레이션하는 리포트 저장소입니다.

## 무엇을 하는 저장소인가요

매주 월요일, 클라우드에서 실행되는 Claude Code 자동화가 다음 세 분야의 최신 논문·GitHub 프로젝트를 검색하고 엄선하여 `reports/` 폴더에 Markdown 리포트로 저장합니다.

1. **생물정보학 (Bioinformatics)** — 멀티오믹스, 다유전자위험점수(PRS), PPI 네트워크 등
2. **LLM 관련 기술** — 의료 QA, 임상노트 요약, 진단 보조 등 의료/생명과학에 응용된 LLM·에이전트·RAG
3. **멀티모달 AI** — 의료영상-텍스트, 병리 이미지, 유전체+이미지 결합 모델 등

일반 도메인 AI 논문은 다루지 않으며, 모든 자료는 **의료 또는 생명공학 데이터 기반 연구**로 한정합니다. "완전한 리뷰"가 아니라 "읽어볼 만한 자료를 빠르게 파악"하는 것이 목적이라 카테고리당 1~2건, 품질 위주로만 선정합니다.

## 자료 선정 기준 (요약)

- JCR 상위 티어(Q1) 저널 논문 우선, 그중에서도 **GitHub 코드가 함께 공개된 논문을 최우선**으로 선정
- 프리프린트(bioRxiv/medRxiv/arXiv)는 원칙적으로 제외 (예외적으로 포함 시 리포트에 명시)
- 이미 소개된 논문·저장소는 재선정하지 않음 (과거 리포트 전체와 대조)

전체 규칙(검색 기간 폴백, 출력 형식 등)은 [CLAUDE.md](./CLAUDE.md)에 자동화 스펙으로 정의되어 있습니다 — 이 저장소를 clone하는 자동화가 매주 그대로 참조하는 실행 지침이므로, 사람이 읽는 소개 문서인 이 README와 역할이 나뉘어 있습니다.

## 리포트 보기

[`reports/`](./reports) 폴더에 `YYYY-MM-DD.md` 형식으로 주차별 리포트가 쌓입니다. 각 리포트는 다음을 포함합니다.

- 그 주 검색 대상 기간과 카테고리별 자료 수
- 자료별 제목(원문 + 한글 설명), 저널명·발행일·JCR 정보
- 핵심 요약 3~5줄, GitHub 링크(있는 경우), 원문 링크(DOI 등)

## 참고

- 리포트는 AI가 웹 검색을 통해 조사·요약한 결과입니다. 저널 등재 여부, 발행일, IF 등 세부 정보는 원문 링크로 직접 확인하시길 권장합니다.
- 자동화는 매주 새 리포트를 커밋·푸시하며, 완료 시 실행 주체에게 알림을 전송합니다.
