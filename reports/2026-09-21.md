## 1. 생물정보학 (Bioinformatics)

### 1-1. EmitGCL — Deep-learning-enabled multi-omics analyses for prediction of future metastasis in cancer
(그래프 대조학습 기반 다중오믹스 통합으로 암의 미래 전이를 예측하는 프레임워크)

- **저널 / 발행일**: Nature Communications, Vol. 17, Article 9309 — 2026-08-01. JCR Q1 (Multidisciplinary Sciences), IF ≈ 14.7
- **검색 기간 폴백**: 기본 기간 및 1개월 확장에서 미보고 자료를 찾지 못해 **3개월로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-08-01)
- **핵심 요약**:
  - 유방암 등 6개 암종·7개 코호트의 단일세포+다중오믹스(유전체, CNV, 전사체) 데이터에 PPI 네트워크 기반 그래프 대조학습(graph contrastive learning)을 적용해 "미래 전이(future metastasis)" 위험을 예측
  - AUC 0.75~0.95로 기존 방법 대비 우수한 성능을 보였고, 영상 검사로는 발견되지 못한 잠재 전이세포를 포착한 사례를 제시
  - 5개 독립 코호트(n=420)에서 HSP90AA1/AB1을 전이 바이오마커로 동정했고, CRISPR 실험으로 전사인자 YY1이 전이의 핵심 드라이버임을 검증
  - 원래 2025년 5월 bioRxiv 프리프린트였으나 현재 정식 저널 게재본이 있어 프리프린트 예외 규정 미적용
- **GitHub**: https://github.com/mtduan/emitgcl (PyPI 패키지 `EmitGCL`로도 배포, pip install 가능) — 다중오믹스+PPI 네트워크 통합 그래프 대조학습 파이프라인과 학습된 전이 위험 스코어링 스크립트를 그대로 재사용 가능 (단, 저장소 star 수 0으로 활성도는 낮은 편)
- **원문 링크**: https://doi.org/10.1038/s41467-026-76277-x (PMC13530145)

### 1-2. GPTL — Improving polygenic score prediction for underrepresented groups through transfer learning
(전이학습을 통해 비유럽계 등 소수집단 대상 다유전자위험점수(PRS) 예측 정확도를 높이는 R 패키지)

- **저널 / 발행일**: Nature Communications, Vol. 17 — 2026-01-23. JCR Q1 (Multidisciplinary Sciences), IF ≈ 14.7
- **검색 기간 폴백**: 3개월 확장까지 미보고 자료를 찾지 못해 **1년으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-01-23)
- **핵심 요약**:
  - 기존 PRS 모델 대부분이 유럽계 GWAS 데이터로 학습되어 비유럽계 인구에서 예측력이 떨어지는 문제를 해결하기 위한 연구
  - 유럽계에서 학습한 정보를 타 인구집단으로 전이하는 3가지 전이학습 기법(조기종료 경사하강법, 사전값으로 수축하는 벌점회귀, 유한혼합 사전분포 기반 베이지안 방법)을 제안
  - 개별 유전형-표현형 데이터 또는 GWAS 요약통계 모두에서 작동하며, 수만 개 변이 규모까지 확장 가능함을 실증
  - 소수인구집단에서 PRS 예측 성능이 유의하게 향상됨을 확인 — 정밀의료의 형평성(equity) 문제에 직접 기여하는 방법론
  - medRxiv 프리프린트(2025-10-08)가 선행됐으나 정식 저널 게재 완료로 프리프린트 예외 규정 미적용
- **GitHub**: https://github.com/QuantGen/GPTL (R 패키지, MIT 라이선스, ★8, 최근 커밋 2026-09-18로 활발히 유지보수 중) — 핵심 알고리즘이 C로 구현되고 R 인터페이스가 제공되어, 요약통계 기반 PRS 파이프라인에 전이학습 모듈을 바로 이식 가능
- **원문 링크**: https://doi.org/10.1038/s41467-026-68696-7 (PMC12932743)

## 2. LLM 관련 기술 (의료/생명과학 응용)

### 2-1. Orchestrator multi-agent clinical decision support system for secondary headache diagnosis in primary care
(1차 진료에서 이차성 두통을 진단하기 위해 가이드라인 기반 "레드플래그" 전문가 에이전트들을 조율하는 오케스트레이터-멀티에이전트 하네스)

- **저널 / 발행일**: Journal of the American Medical Informatics Association (JAMIA) — 온라인 공개 2026-06-27 (PMID 42364078). JCR Q1 (Medical Informatics), IF ≈ 7.1
- **검색 기간 폴백**: 기본 기간 및 1개월 확장에서 미보고 자료를 찾지 못해 **3개월로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-06-27)
- **핵심 요약**:
  - 이차성 두통 진단을 7개의 임상 가이드라인 기반 "레드플래그" 전문가 에이전트로 분해하고, 중앙 오케스트레이터가 이를 조율해 구조화된 근거 기반 판단을 도출하는 멀티에이전트 하네스 설계
  - 전문가가 검증한 1차 진료 두통 사례(vignette) 90건을 대상으로, 질문 기반 프롬프트(QPrompt)와 임상 가이드라인 기반 프롬프트(GPrompt) 두 전략 하에 5개 오픈소스 LLM(Qwen-8B/14B/30B, GPT-OSS-20B, Llama-3.1-8B)에서 단일 LLM 베이스라인과 비교
  - 오케스트레이션된 멀티에이전트 + GPrompt 조합이 레드플래그 분류에서 가장 높은 F1을 일관되게 달성했고, 특히 소형 모델에서 개선폭이 컸음 — 성능 향상의 핵심이 멀티에이전트 구조 자체가 아니라 "가이드라인 기반 구조적 분해"임을 시사
- **GitHub**: https://github.com/PittNAIL/Jamia-Headache-Paper-Gold-Standard-Data-and-Result — 골드스탠다드 테스트 케이스·레드플래그 주석·결과 데이터 공개 (프로토타입 "Merlin App"은 Docker Hub `yanshanwang/merlin`으로 별도 배포) — 가이드라인 기반 진단 에이전트 하네스를 설계할 때 평가 데이터셋과 오케스트레이터/전문가 에이전트 참조 구현으로 활용 가능
- **원문 링크**: https://doi.org/10.1093/jamia/ocag111 (PMC13419605)

### 2-2. Reinforcement learning improves LLM accuracy and reasoning in disease classification from radiology reports
(지도학습 미세조정 후 강화학습(GRPO)을 추가해 방사선 판독문 질환 분류의 정확도와 추론 품질을 동시에 개선)

- **저널 / 발행일**: npj Digital Medicine — 2026-04-30 (PMID 42062541). JCR Q1 (Medical Informatics/Digital Health), IF ≈ 18.0
- **검색 기간 폴백**: 3개월 확장까지 미보고 자료를 찾지 못해 **6개월로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-04-30)
- **핵심 요약**:
  - Weill Cornell Medicine bionlp lab(Wei, Lin, Flanders, Shih, Peng) 개발
  - 경량 LLM의 지도학습 미세조정(SFT)이 분류 정확도는 높이지만 추론 품질을 저하시킬 수 있다는 문제에 착안, SFT 이후 Group Relative Policy Optimization(GRPO) 강화학습 단계를 추가하는 2단계 파이프라인을 제안
  - MIMIC-CXR, NIH-CXR, MIDRC 등 방사선전문의 주석 흉부 X-ray 판독문 3개 데이터셋·13개 폐질환/소견에서 검증
  - SFT만으로도 제로/퓨샷 베이스라인 대비 우수했고, GRPO를 추가하면 분류 정확도뿐 아니라 모델이 제시하는 추론 설명의 재현율(recall)·포괄성까지 함께 개선됨을 확인
- **GitHub**: https://github.com/bionlplab/radiology-disease-classification — SFT+GRPO 학습 파이프라인과 데이터 공개, 구조화된 임상 텍스트 분류 과제에서 해석 가능한 추론을 유지하며 경량 LLM을 미세조정하는 레시피로 재사용 가능
- **원문 링크**: https://doi.org/10.1038/s41746-026-02685-4 (PMC13338140)

## 3. 멀티모달 AI

### 3-1. TITAN — Multimodal Whole-Slide Foundation Model for Pathology
(병리 전신 슬라이드 이미지와 병리 리포트 텍스트를 함께 학습한 멀티모달 병리 파운데이션 모델)

- **저널 / 발행일**: Nature Medicine, Vol. 31, pp. 3749–3761 — 온라인 공개 2025-11경(인쇄판 2025년 11월). JCR Q1 최상위, IF ≈ 50~58
- **검색 기간 폴백**: 6개월 확장까지 미보고 자료를 찾지 못해 **1년으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2025-11경). 참고: 2026-08-14 리포트에서 TITAN은 타 논문("오픈소스 병리 파운데이션 모델 벤치마킹")의 비교 대상 베이스라인으로만 언급되었을 뿐, TITAN 원 논문 자체가 선정된 적은 없음
- **핵심 요약**:
  - 2만 명 이상 환자에서 확보한 33만 5,645장의 병리 WSI를 시각 자기지도학습과 실제 병리 리포트 + AI가 생성한 합성 캡션(423,122건) 기반 비전-언어 정렬로 함께 사전학습
  - 별도의 태스크별 파인튜닝 없이 선형 프로빙, 퓨샷/제로샷 분류, 희귀암 검색, 교차모달 검색, 병리 리포트 자동 생성 등 다양한 다운스트림 과제에서 기존 ROI 단위·슬라이드 단위 파운데이션 모델 대비 우수한 성능을 달성
  - 원래 arXiv 프리프린트(2411.19666)로 공개됐으나 현재 Nature Medicine 정식 게재본이 있어 프리프린트 예외 규정 미적용
- **GitHub**: https://github.com/mahmoodlab/TITAN (★370, Hugging Face에 사전학습 가중치 공개 `MahmoodLab/TITAN`) — 슬라이드 인코더와 리포트 생성 파이프라인을 그대로 활용해 자체 WSI 코호트에 다운스트림 병리 AI 과제 적용 가능
- **원문 링크**: https://doi.org/10.1038/s41591-025-03982-3

### 3-2. PathGen — Generating Crossmodal Gene Expression from Cancer Histopathology Predicts Multimodal Decision Utility
(병리 이미지 임베딩만으로 유전자 발현 프로파일을 생성해, 영상만 있어도 유전체 정보가 있는 것처럼 예측 성능을 높이는 확산모델)

- **저널 / 발행일**: Nature Communications — 2025-12-31. JCR Q1 (Multidisciplinary Sciences), IF ≈ 14.7
- **검색 기간 폴백**: 6개월 확장까지 미보고 자료를 찾지 못해 **1년으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2025-12-31)
- **핵심 요약**:
  - 파운데이션 모델 기반 WSI 패치 임베딩을 조건으로 확산모델(diffusion model)을 학습시켜, 조직병리 이미지만으로 합성 전사체(transcriptomic) 특징을 생성
  - TCGA·CPTAC의 4개 암 코호트(교모세포종/신경교종, 신장암, 자궁암, 유방암)에서 검증
  - 생성된 교차모달 유전자 발현 특징을 조직병리와 결합했을 때, 암 등급 분류와 생존 위험 계층화(survival-risk stratification)에서 최신 성능을 달성 — 영상 전용 워크플로우에 유전체 기반 정보를 보강하는 실용적 접근
  - 유전체+이미지 결합이라는 CLAUDE.md 멀티모달 카테고리 예시에 정확히 부합하는 사례
  - arXiv 프리프린트(2502.00568)가 선행됐으나 정식 저널 게재본이 있어 프리프린트 예외 규정 미적용
- **GitHub**: https://github.com/Samiran-Dey/PathGen (★14) — 확산모델 기반 유전자 발현 생성 파이프라인과 다운스트림 생존/등급분류 평가 코드 공개, 자체 병리 이미지 코호트에 유전체 정보 보강 파이프라인 적용 가능
- **원문 링크**: https://doi.org/10.1038/s41467-025-66961-9
