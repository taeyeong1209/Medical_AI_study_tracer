## 1. 생물정보학 (Bioinformatics)

### Multiomics Modeling for Microsatellite Instability Prediction in Colorectal Cancer
- **저널 / 발행일**: Academic Radiology / 2026-08-13
- **JCR 분류·IF**: Q1 (Radiology, Nuclear Medicine & Medical Imaging 분야), IF ≈ 4.7
- **저자**: Ao W, Huang Y, Mao G, Wang W, Huang D, Zheng Y, Deng S
- **핵심 요약**:
  - 대장암(Colorectal Cancer)에서 면역치료 반응과 밀접한 미세위성불안정성(MSI) 상태를 예측하기 위한 다중모달(multimodal) 딥러닝 프레임워크를 제안
  - CT 영상 분석과 조직병리(histopathology) 정보를 결합하여 단일 모달리티 대비 예측력을 높이는 방향으로 설계됨
  - MSI 상태는 면역관문억제제 치료 대상자 선별에 중요한 바이오마커로, 비침습적/저비용 예측 모델의 임상적 가치가 큼
  - 정확한 정량적 성능 지표는 원문 확인 필요 (초록 상세 정보 접근 제한)
- **GitHub**: 확인되지 않음
- **원문 링크**: https://doi.org/10.1016/j.acra.2026.07.069 (PMID: 42595634)

## 2. LLM 관련 기술 (의료/생명과학 응용)

### A large language model-driven multidisciplinary AI agent system predicts delirium in emergency critically ill patients (DeLiriuMAgents)
- **저널 / 발행일**: Cell Reports Medicine (Cell Press) / 2026-08-13
- **JCR 분류·IF**: Q1, IF ≈ 14.0
- **저자**: Shang W, Shi T, Ma Q, Kong G
- **핵심 요약**:
  - 응급실·중환자실 환자를 대상으로 섬망(delirium) 위험을 조기에 예측하는 "DeLiriuMAgents"라는 LLM 기반 다학제(multidisciplinary) AI 에이전트 시스템을 제안
  - 기존 예측 모델들이 갖는 해석가능성(interpretability) 한계를 개선하는 것을 주요 목표로 삼음
  - 여러 전문 분야(간호, 중환자의학 등) 관점을 에이전트 오케스트레이션으로 통합해 임상 의사결정을 지원하는 접근
  - 하네스/에이전트 오케스트레이션 관점에서 다학제 협진 워크플로우를 LLM 에이전트로 모사한 사례로 참고할 만함
- **GitHub**: 확인되지 않음 (논문 내 코드 공개 여부 원문 확인 필요)
- **원문 링크**: https://doi.org/10.1016/j.xcrm.2026.102986 (PMID: 42594876)

## 3. 멀티모달 AI

### Benchmarking Open-Source Pathology Foundation Models for Breast Cancer Biomarker Prediction from H&E Whole-Slide Images
- **저널 / 발행일**: Cancers (MDPI) / 2026-08-01
- **JCR 분류·IF**: Q2 (Oncology 분야), IF ≈ 4.8 — Q1 기준에는 못 미치나, 오픈소스 병리 파운데이션 모델의 실전 벤치마킹이라는 실용적 가치가 높아 예외적으로 포함
- **저자**: Atiya S, Liang J, Ofori-Atta K, Peng M, Wang H, Zhou Y, Patel A, Edgerton M, Zhao J, Pamuksuz U
- **핵심 요약**:
  - 오픈소스 병리 파운데이션 모델인 TITAN(약 4850만 파라미터)과 CHIEF(약 120만 파라미터)를 H&E 염색 유방암 WSI(Whole-Slide Image)에서 ER/PR/HER2 바이오마커 상태 예측에 벤치마킹
  - TCGA-BRCA(The Cancer Genome Atlas Breast Invasive Carcinoma) 데이터를 NCI Imaging Data Commons를 통해 확보하여 검증
  - 병리 이미지(멀티모달 파운데이션 모델)를 실제 임상 바이오마커 예측 태스크에 적용했을 때의 실전 성능 차이를 비교 분석
  - 오픈소스 모델 간 비교이므로, 자체 학습 없이도 기존 파운데이션 모델을 임상 태스크에 활용하는 파이프라인 설계에 참고 가능
- **GitHub**: TITAN·CHIEF 원 모델은 각각 오픈소스로 공개되어 있음(원 개발팀 저장소). 본 벤치마킹 논문 자체의 코드 공개 여부는 확인되지 않음
- **원문 링크**: https://www.mdpi.com/2072-6694/18/15/2475
