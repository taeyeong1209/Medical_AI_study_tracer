## 1. 생물정보학 (Bioinformatics)

### 1-1. From Text to Translation: Using Language Models to Prioritize Variants for Clinical Review (ClinVar-BERT)
(ClinVar의 자유기술형(free-text) 변이 요약문을 분석해 병원성/양성 분류 근거 패턴을 학습하는 언어모델 기반 임상 변이 재검토 우선순위화 프레임워크)

- **저널 / 발행일**: Genome Medicine — 2026-05-19 (저자: Weijiang Li, Xiaomin Li, Ethan Lavallee, Alice Saparov, Marinka Zitnik, Christopher Cassa). JCR 분류·IF: Q1 (Genetics & Heredity), 2025 JCR 기준 IF ≈ 11 내외로 추정(2차 소스 기준, 미검증). **정확한 Genome Medicine DOI는 이번 조사에서 확인하지 못함**(journal 사이트·bwhgenetics.org가 네트워크 정책상 접근 차단되어 1차 소스 확인 불가; 선행 medRxiv 프리프린트 DOI: 10.1101/2024.12.31.24319792)
- **검색 기간 폴백**: 기본 기간(2026-10-27~11-02)·1개월·3개월 확장까지 조건을 만족하는 미보고 자료를 찾지 못해 **6개월(2026-05-03~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-05-19). 선행 medRxiv 프리프린트(2024-12)의 정식 저널 출판본이므로 프리프린트 제외 규정에 해당하지 않음
- **핵심 요약**:
  - Brigham and Women's Hospital/Broad Institute 소속 Cassa Lab 연구팀 개발
  - BioBERT 기반으로 파인튜닝한 "ClinVar-BERT"를 ClinVar의 240만 건 이상 자유기술형 변이 요약문으로 학습시켜, 병원성/양성/불확실(VUS) 분류 확률을 산출
  - 기능적 스크리닝 데이터와 교차검증한 결과 VUS 변이 분류에서 AUROC 0.927을 달성했으며, BRCA1·TP53·PTEN 등 임상적으로 조치 가능한(actionable) 유전자에서 기능적 영향의 유의한 분리를 보고
  - 전문가 재검토가 필요한 변이 후보를 우선순위화하는 진단 실험실·전문가 큐레이션 보조 도구로 제안됨
- **GitHub**: 이번 조사에서 ClinVar-BERT 자체의 공개 코드 저장소는 확인하지 못함(예측 결과 조회용 웹 데모 https://weijiang99-clinvarbert-predictions.hf.space/ 는 확인됨) — 코드 공개 여부 불확실
- **원문 링크**: Genome Medicine (2026-05-19, DOI 미확인); 선행 프리프린트 https://doi.org/10.1101/2024.12.31.24319792

## 2. LLM 관련 기술 (의료/생명과학 응용)

### 2-1. An autonomous agentic workflow for clinical detection of cognitive concerns using large language models
(5개 LLM 에이전트가 서로의 판단을 토론·검증하며 임상노트에서 인지기능 저하 징후를 자동 선별하는 완전 자율 에이전틱 워크플로우. 함께 공개된 오픈소스 자율 프롬프트 최적화 도구 "Pythia" 포함)

- **저널 / 발행일**: npj Digital Medicine — 2026-01-29경 (DOI: 10.1038/s41746-025-02324-4, 저자: Jiazi Tian, Hossein Estiri 등). JCR 분류·IF: Q1 (Digital/Health Informatics 상위권으로 추정, 정확한 IF 수치는 미검증)
- **검색 기간 폴백**: 기본 기간(2026-10-27~11-02)부터 1개월·3개월·6개월 확장까지 조건을 만족하는 미보고 자료를 찾지 못해 **1년(2025-11-02~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-01-29경, 정확한 일자는 2차 소스 기준 추정)
- **핵심 요약**:
  - Mass General Brigham(MGB) 연구팀 개발
  - Llama·Med42 기반 5개의 전문화된 LLM 에이전트가 서로의 판단을 디베이트 방식으로 검토·개선하는 완전 자율 에이전틱 워크플로우를 설계해, 전문가가 수동 설계한 프롬프트 최적화 방식과 비교
  - MGB 환자 200명, 임상노트 3,300여 건 데이터에서 자율 워크플로우가 F1 0.93을 달성해 전문가 주도 프롬프트 최적화(F1 0.87)를 상회했고, 실제 환경(독립) 검증에서 특이도 98%를 보고(단, 소스마다 F1 수치에 일부 편차 있어 원문 확인 필요)
  - 병원 내부망에서 구동 가능한 오픈소스 모델 기반으로 설계되어 환자 데이터가 외부로 전송되지 않으며, 스크리닝 보조(진단 대체 아님) 목적으로 제안됨
- **GitHub**: https://github.com/clai-group/Pythia — 다중 에이전트 협업 기반 자율 프롬프트 최적화 프레임워크(Pythia)가 공개되어, 라벨링된 자체 데이터셋에 대해 프롬프트를 반복 개선하는 파이프라인으로 타 임상 분류/스크리닝 과제에 바로 적용 가능
- **원문 링크**: https://doi.org/10.1038/s41746-025-02324-4

## 3. 멀티모달 AI

### 3-1. CLEAR: An auditable foundation model for radiology grounded in clinical concepts
(흉부 X-ray 영상을 36만여 개의 임상 관찰 소견(텍스트) 공간에 투영하여, 예측 결과를 개별 소견별 기여도로 분해·감사(audit) 가능하게 만든 영상-텍스트 멀티모달 파운데이션 모델)

- **저널 / 발행일**: Nature Biomedical Engineering — 2026-07 (DOI: 10.1038/s41551-026-01741-4, 저자: Tianyu Han, Yan Wu, Jiazi Tian 등). JCR 분류·IF: Q1 (Engineering, Biomedical), 2026 IF ≈ 26.3(3차 소스 추정, 미검증)
- **검색 기간 폴백**: 기본 기간(2026-10-27~11-02)·1개월·3개월 확장까지 미보고 자료를 찾지 못해 **6개월(2026-05-02~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-07, 정확한 일자 미확인)
- **핵심 요약**:
  - 흉부 X-ray를 방사선 보고서에서 추출한 368,294개 임상 관찰 소견과의 유사도 벡터로 변환하고 LLM 임베딩 공간에 투영하여, 예측을 개별 소견의 가중 기여도로 분해(감사 가능)하는 zero-shot 분류·개념 병목(concept bottleneck) 모델
  - 239,391명 환자의 이미지-보고서 쌍 873,342건(MIMIC-CXR, CheXpert-Plus, ReXGradient)으로 사전학습, 미국·유럽·아시아 4개 외부 데이터셋에서 검증
  - PadChest 외부 zero-shot 평가에서 폐렴 탐지 AUC 0.937(95% CI 0.922–0.950)로 CheXzero(0.889), BiomedCLIP(0.675) 대비 우수하며, CheXpert 5개 경쟁 병리 소견에서 전문 방사선의 3인과 동등한 수준을 보고
- **GitHub**: https://github.com/peterhan91/CLEAR (Apache-2.0, ★15, Hugging Face `peterhan91/CLEAR`에 DINOv2 ViT-B/14 기반 사전학습 가중치 공개) — 이미지 인코더와 개념 뱅크 유틸리티를 활용해 자체 흉부 X-ray 데이터셋에 설명 가능한 zero-shot 진단·소견별 감사 파이프라인 구축 가능(연구용 한정, 의료기기 미승인). 참고: 동명의 다른 "CLEAR"(katherlab/clear, 3D CT 모델, MICCAI 2025)와는 별개 연구임
- **원문 링크**: https://doi.org/10.1038/s41551-026-01741-4
