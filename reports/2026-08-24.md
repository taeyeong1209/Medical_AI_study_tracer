## 2. LLM 관련 기술 (의료/생명과학 응용)

### DeepRare — An agentic system for rare disease diagnosis with traceable reasoning
(추적 가능한 근거 기반 추론을 제공하는 희귀질환 진단 LLM 에이전트 시스템)

- **저널 / 발행일**: Nature, Vol. 651, pp. 775–784 / 온라인 공개 2026-02-18 — Q1 최상위 종합 저널
- **검색 기간 폴백**: 3개월까지 확장했으나 품질 기준(Q1+GitHub 공개)을 만족하는 미보고 자료를 찾지 못해 **6개월로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-02-18)
- **핵심 요약**:
  - LLM 기반 멀티에이전트 시스템으로, 자유텍스트 임상 기술·구조화된 HPO(Human Phenotype Ontology) 표현형 용어·유전자 검사 결과 등 이질적 임상 입력을 처리
  - 40개 이상의 전문 도구와 최신 지식소스를 통합해 근거가 명시적으로 연결된(traceable) 순위화 감별진단 가설을 생성
  - 기존 생물정보학 진단 도구·단일 LLM·타 에이전트 시스템 등 15개 비교 방법 대비 HPO 기반 평가에서 Recall@1 57.18%로 2위(Reasoning LLM) 대비 23.79%p 큰 격차로 우위
  - 멀티모달 입력 시나리오(109개 사례)에서도 Recall@1 70.60%로 기존 도구 Exomiser(53.20%) 대비 우수
  - 실제 임상의와의 헤드투헤드 비교에서도 희귀질환 진단 정확도가 더 높음을 확인
- **GitHub**: https://github.com/MAGIC-AI4Med/DeepRare — 코드 공개, 자체 임상 케이스에 대해 다중 도구 기반 감별진단 에이전트 파이프라인을 재현·적용 가능
- **원문 링크**: https://doi.org/10.1038/s41586-025-10097-9 (PMID 41708847)

## 3. 멀티모달 AI

### PRISM2 — End-to-end multimodal pathology foundation model with clinical dialogue
(임상 대화 지도학습 기반 멀티모달 병리 파운데이션 모델)

- **저널 / 발행일**: Nature Medicine / 2026-07-31 — Q1 최상위 의생명 저널
- **검색 기간 폴백**: 기본 기간(직전 10일) 내 미보고 자료를 찾지 못해 **1개월로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-07-31)
- **핵심 요약**:
  - Tempus AI가 Microsoft 연구진과 공동 개발, 병리 전신 슬라이드 이미지(WSI) 230만 장과 70만 건의 병리 리포트에서 추출한 1,400만 개 질의응답 쌍으로 학습
  - 임상 대화(clinical dialogue) 지도를 통해 조직형태(histomorphology)와 진단적 추론을 정렬시켜, 프롬프트 기반 추론과 다운스트림 전이 가능한 임베딩을 모두 지원
  - 전립선·유방·유방림프절 암 검출에서 임상등급 상용 제품과 동등하거나 유의하게 우수한(P < 0.05) balanced accuracy를 달성
- **GitHub**: 확인되지 않음 (Tempus/Microsoft 상용 모델로, 공개 코드 저장소는 확인되지 않음 — 관련 arXiv 프리프린트: 2506.13063)
- **원문 링크**: https://doi.org/10.1038/s41591-026-04521-4
