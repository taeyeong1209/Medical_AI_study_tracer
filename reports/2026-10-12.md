## 1. 생물정보학 (Bioinformatics)

### 1-1. Multiomics and deep learning dissect regulatory syntax in human development (HDMA)
(단일세포 멀티오믹스와 딥러닝으로 인간 발달 과정의 유전자 조절 "문법(regulatory syntax)"을 해독한 연구)

- **저널 / 발행일**: Nature, Vol. 653 — 온라인 공개 2026-04-08. JCR 분류·IF: Q1 최상위 종합 저널, 2025 JCR 기준 IF ≈ 48~50
- **검색 기간 폴백**: 기본 기간부터 3개월 확장까지 미보고 자료를 찾지 못해 **6개월(2026-04-12~)까지 확장했으나 역시 발견하지 못하고, 1년(2025-10-12~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-04-08)
- **핵심 요약**:
  - Stanford Greenleaf Lab(Betty B. Liu, Selin Jessa, Anshul Kundaje, Kyle Farh, William J. Greenleaf 등) 개발
  - 12개 장기·203개 세포유형에서 확보한 태아 세포 817,740개의 크로마틴접근성(scATAC)+전사체(scRNA) 공동측정 멀티오믹스 데이터로 "Human Development Multiomic Atlas(HDMA)"를 구축하고, 100만 개 이상의 후보 시스-조절요소(cCRE)를 식별
  - DNA 서열만으로 접근성을 예측하는 딥러닝 모델을 학습해 전사인자 결합 모티프 어휘집을 도출하고, 모티프 간 간격·방향이 엄격히 요구되는 "hard rule"과 유연하게 허용되는 "soft rule" 등 조절 서열의 "문법적 구조"를 규명
  - 모티프를 교란했을 때 유전자 발현 변화와 일관된 패턴을 보여, 이 프레임워크를 질병 관련 유전변이의 조절 효과 해석에 활용할 수 있음을 입증 (2025년 bioRxiv 프리프린트가 선행됐으나 현재 Nature 정식 게재본이 있어 프리프린트 예외 규정 미적용)
- **GitHub**: https://github.com/GreenleafLab/HDMA (분석 코드 전체 공개, Zenodo 아카이브 병행) — 자체 단일세포 멀티오믹스(scATAC+scRNA) 데이터에 서열 기반 접근성 예측 모델과 모티프 문법 분석 파이프라인을 적용해 발달·질환 관련 조절변이 해석에 활용 가능
- **원문 링크**: https://doi.org/10.1038/s41586-026-10326-9

### 1-2. EEPRS — Improving polygenic risk prediction performance by integrating electronic health records through phenotype embedding
(전자건강기록(EHR) 진단 코드의 표현형 임베딩을 다유전자위험점수(PRS) 예측에 결합해 정확도를 높이는 방법론)

- **저널 / 발행일**: The American Journal of Human Genetics (AJHG, Cell Press), Vol. 112, Issue 12, pp. 3030–3045 — 2025-12-04. JCR 분류·IF: Q1 (Genetics & Heredity, 약 12/191위권), 2025 JCR 기준 IF ≈ 8.1 (5년 IF ≈ 9.6)
- **검색 기간 폴백**: 기본 기간부터 6개월 확장까지 미보고 자료를 찾지 못해 **1년(2025-10-12~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2025-12-04)
- **핵심 요약**:
  - Yale Hongyu Zhao 연구팀(제1저자 Leqi Xu) 개발
  - 기존 PRS는 GWAS 요약통계만 활용해 EHR에 담긴 풍부한 임상 정보를 반영하지 못한다는 한계에 착안, EHR 진단 코드에 Word2Vec·GPT 기반 임베딩을 적용해 "표현형 임베딩"을 생성하고 이를 GWAS와 결합한 EEPRS(EHR-embedding-enhanced PRS) 제안
  - UK Biobank 유럽계 코호트 41개 임상 형질과 All of Us 7개 질환에서 검증
  - 기존 단일형질 PRS 대비 연속형 형질 R² 평균 15.6%, 이진 형질(질환) AUC 평균 4.65% 향상. 유전상관 기반 계층적 군집에서 뚜렷한 심혈관질환 클러스터를 발견했으나, 유방암·관상동맥질환처럼 기존 대형 GWAS로도 이미 예측력이 높은 질환에서는 추가 이득이 제한적
- **GitHub**: 공개 저장소를 확인하지 못함(저자명·소속 연구실·bioRxiv 프리프린트까지 교차 검색했으나 미발견 — 이번 세션 네트워크 정책상 논문 원문의 Code Availability 절을 직접 열람하지 못해 완전히 배제하지는 못함)
- **원문 링크**: https://doi.org/10.1016/j.ajhg.2025.11.006 (PMID 41349513, PMC12695032; 선행 bioRxiv 프리프린트 10.1101/2025.08.05.668705)

## 2. LLM 관련 기술 (의료/생명과학 응용)

### 2-1. MedAgentBrief — Physician-Reported Safety Outcomes of AI-Generated Hospital Course Summaries
(에이전틱 LLM이 매일 밤 입원경과요약 초안을 작성하고, 실제 임상 현장에서 담당 의사가 안전성·유용성을 평가한 전향적 파일럿 연구)

- **저널 / 발행일**: JAMA Network Open, 9(5):e2616556 — 2026-05-01. JCR 분류·IF: Q1 (General & Internal Medicine), 2025 JCR 기준 IF ≈ 9.7~11.7 (출처별 상이)
- **검색 기간 폴백**: 기본 기간부터 3개월 확장까지 미보고 자료를 찾지 못해 **6개월(2026-04-12~)로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-05-01)
- **핵심 요약**:
  - Stanford 입원내과 1개 병동에서 10주간(2025-08-01~10-11) 시행된 전향적 단일군 파일럿 연구
  - Gemini 2.5 Pro 기반 에이전틱 LLM 워크플로우(MedAgentBrief)가 서명 완료된 병력·경과기록을 입력받아 매일 밤 입원경과요약(Hospital Course) 초안을 작성해 담당 의사에게 이메일로 전달
  - 1차 평가지표는 미수정 AI 초안에 대한 담당 의사의 직접적인 "잠재적 위해(harm)" 평가로, 384건의 입원 중 생성된 1,274건의 요약 가운데 219건(57%)이 실제 최종 퇴원요약에 (수정을 거쳐) 사용됨. 미수정 요약의 88%는 위해 가능성 없음으로 평가됨
  - 피드백이 있었던 요약 100건 중 누락 25%, 부정확 20%, 환각 2%가 확인됐으나, 임상의 소진(burnout) 완화와 문서작성 시간 단축과도 연관됨 — 벤치마크가 아닌 실제 임상 배치(real-world deployment) 환경에서 환자안전·워크플로우 영향까지 검증한 드문 사례
- **GitHub**: 확인되지 않음 (Stanford 병원 EHR 연동 특성상 비공개일 가능성이 높으며, 관련 방법론 선행 논문(Pacific Symposium on Biocomputing 2026, arXiv:2509.05878)까지 검색했으나 공개 코드 저장소를 찾지 못함)
- **원문 링크**: https://doi.org/10.1001/jamanetworkopen.2026.16556 (PMID 42101844)

### 2-2. Benchmarking large language model-based agent systems for clinical decision tasks
(오픈소스·상용 임상 LLM 에이전트 시스템을 복수의 임상 의사결정 벤치마크에서 비교 평가해, 에이전트 하네스의 실질적 효용과 비용을 정량 분석한 비판적 벤치마크 연구)

- **저널 / 발행일**: npj Digital Medicine, Vol. 9, Article 259 — 2026-02-18. JCR 분류·IF: Q1 (Medical Informatics/Digital Health), 2025 JCR 기준 IF ≈ 15~18 (출처별 상이)
- **검색 기간 폴백**: 기본 기간부터 6개월 확장까지 미보고 자료를 찾지 못해 **1년(2025-10-12~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-02-18)
- **핵심 요약**:
  - DKFZ/TU Dresden Kather Lab(Liu Y, Carrero ZI, Jiang X, Wölflein G, Kather JN 등) 개발
  - 오픈소스 에이전트 시스템 OpenManus(Llama-4 기반 의료 특화 확장)와 상용 에이전트 Manus(planner-executor-verifier 구조)를 AgentClinic, MedAgentsBench, Humanity's Last Exam(HLE) 세 벤치마크에서 비교해 "에이전틱 하네스/오케스트레이션이 단일 LLM 대비 얼마나 실질적 이득을 주는가"를 정량 평가
  - AgentClinic(MedQA 60.3%, MIMIC 28.0%), MedAgentsBench(30.3%), HLE 텍스트(+8.6%)·멀티모달(+15.5%) 등에서 에이전트 구조의 정확도 향상은 제한적인 반면, 토큰 사용량 10배 이상·지연시간 2배 이상 증가라는 상당한 비용이 수반됨을 확인
  - 환각(hallucination)은 여전히 빈발했으나 에이전트 내 안전장치가 다수를 필터링 — 현재 세대의 임상 에이전트 하네스가 "비용 대비 효용이 제한적"이라는 비판적 결론을 제시해, 하네스 설계 시 비용·효용 트레이드오프를 재고할 필요성을 시사
- **GitHub**: 확인되지 않음 (저자 소속 Kather Lab은 평소 코드 공개 관행이 있으나, 이번 세션 네트워크 정책상 Nature 원문의 Code Availability 절을 직접 열람하지 못해 완전히 배제하지는 못함)
- **원문 링크**: https://doi.org/10.1038/s41746-026-02443-6

## 3. 멀티모달 AI

### 3-1. Merlin — A Vision-Language Foundation Model and Dataset for 3D Computed Tomography
(3차원 복부 CT 영상과 방사선 판독문을 함께 학습한 대규모 비전-언어 파운데이션 모델)

- **저널 / 발행일**: Nature — 온라인 공개 2026-03-04. JCR 분류·IF: Q1 최상위 종합 저널, 2025 JCR 기준 IF ≈ 48~50
- **검색 기간 폴백**: 기본 기간부터 6개월 확장까지 미보고 자료를 찾지 못해 **1년(2025-10-12~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-03-04)
- **핵심 요약**:
  - Stanford Chaudhari Lab(Louis Blankemeier, Akshay S. Chaudhari 등) 개발
  - 15,331건의 복부 CT 스캔(600만 장 이상 이미지), 180만 건 이상의 진단 코드, 600만 토큰 이상의 방사선 판독문으로 구성된 대규모 데이터셋을 구축해 3D CT-텍스트 비전-언어 파운데이션 모델을 사전학습
  - 제로샷 소견 분류, 표현형 분류, 영상-판독문 검색, 5년 만성질환 예측, 방사선 판독문 생성, 3D 장기 분할 등 6개 과제 유형·752개 개별 태스크에서 평가해 기존 CT 특화 모델 대비 우수한 범용 성능을 입증
  - 원래 2024년 arXiv 프리프린트(2406.06512)로 먼저 공개됐으나, 이번에 Nature 정식 게재본이 확인되어 프리프린트 예외 규정은 미적용. 코드·모델 가중치와 함께 비식별화된 CT 데이터셋 접근 경로까지 공개한 드문 사례
- **GitHub**: https://github.com/StanfordMIMI/Merlin (코드·사전학습 가중치·데이터셋 접근 안내 공개, 설치 가이드·데모 포함) — 자체 CT 코호트에 사전학습 인코더를 파인튜닝해 소견 분류·판독문 생성·장기 분할 등 다운스트림 과제에 바로 활용 가능
- **원문 링크**: https://doi.org/10.1038/s41586-026-10181-8

### 3-2. Glio-LLaMA-Vision — A robust vision language model for molecular status prediction and radiology report generation in adult-type diffuse gliomas
(다중 파라미터 뇌 MRI와 방사선 판독문을 결합해 성인형 미만성 신경교종의 분자아형을 예측하고 판독문을 자동 생성하는 비전-언어 모델)

- **저널 / 발행일**: npj Digital Medicine, Vol. 9 — 2026-04-02. JCR 분류·IF: Q1 (Medical Informatics/Digital Health), 2025 JCR 기준 IF ≈ 15~18 (출처별 상이)
- **검색 기간 폴백**: 기본 기간부터 6개월 확장까지 미보고 자료를 찾지 못해 **1년(2025-10-12~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-04-02)
- **핵심 요약**:
  - Yae Won Park 등(Yonsei 계열 연구팀) 개발
  - LLaMA 3.1을 기반으로 PubMed Central의 279만 건 의생명과학 이미지-텍스트 쌍으로 사전학습한 뒤, 성인형 미만성 신경교종 환자 1,001명의 다중 파라미터 MRI와 짝지어진 방사선 판독문으로 파인튜닝한 비전-언어 모델(Glio-LLaMA-Vision) 제안
  - IDH 돌연변이 등 분자상태 예측과 방사선 판독문 자동 생성을 동시에 수행하는 멀티태스크 구조
  - 내부검증·외부검증 데이터셋에서 IDH 돌연변이 예측 AUC 0.85~0.95(정확도 86.0%)를 달성했고, 생성된 판독문은 BLEU-1 0.49·ROUGE-L 0.42·METEOR 0.24, 임상적으로 수용 가능하다고 평가된 비율 91.3%를 기록 — 고비용 분자병리 검사 없이도 표준 MRI만으로 유사한 정보에 접근 가능함을 시사
- **GitHub**: 확인되지 않음 (2025 SNO 학술대회 초록까지 포함해 검색했으나 공개 코드 저장소를 찾지 못함; 이번 세션 네트워크 정책상 원문의 Code Availability 절 직접 열람 제한으로 완전히 배제하지는 못함)
