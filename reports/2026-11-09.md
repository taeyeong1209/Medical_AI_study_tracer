## 1. 생물정보학 (Bioinformatics)

### 1-1. CellVQ — Illuminating cell states by a comprehensive and interpretable single cell foundation model
(약 5.1억 파라미터 규모의 단일세포 파운데이션 모델로, 세포 표현을 "cell code"로 벡터 양자화(vector quantization)하여 세포 상태를 해석 가능하게 만든 인코더-SCD-디코더 구조 모델)

- **저널 / 발행일**: Nature Communications, Vol. 17, Article 4037 — 2026-03-16 (DOI: 10.1038/s41467-026-70071-5, PMID 41839876, 저자: Jue Wang, Chen Tan, Stan Z. Li). JCR 분류·IF: Q1 (Multidisciplinary Sciences), 2025 JCR 기준 IF 추정치는 2차 소스로 확인하지 못함(통상 10대 중후반으로 알려져 있으나 미검증)
- **검색 기간 폴백**: 기본 기간(2026-11-03~11-09)·1개월·3개월·6개월 확장까지 조건을 만족하는 미보고 자료를 찾지 못해 **1년(2025-11-09~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-03-16)
- **핵심 요약**:
  - 약 6,800만 개 이상의 단일세포 데이터(scRNA-seq/scATAC-seq)로 사전학습된 단일세포 파운데이션 모델로, Single-Cell Discretization(SCD) 모듈을 통해 각 세포 표현을 하나의 이산적 "cell code"로 변환
  - 세포 클러스터링·주석, 유전자/약물 섭동(perturbation) 예측, 약물 반응 예측 등 예측 과제와, 세포 상태·유전자 발견, 유전자 조절 네트워크(GRN) 분석 등 해석 과제를 동시에 지원하도록 설계되어 해석가능성(interpretability)에 중점
  - CellVQ-Graph라는 지식그래프를 함께 구축해 모델 예측 결과의 해석을 보강했다고 보고 (정량적 성능 지표의 세부 수치는 이번 조사에서 원문 전체를 확인하지 못해 추가 검증 필요)
- **GitHub**: https://github.com/A4Bio/CellVQ (MIT, ★15, 16 commits, 최근 커밋 날짜는 확인하지 못함) — 사전학습 가중치와 추론 스크립트(`inference.py`, `quick_start.ipynb`)가 공개되어 있어, 자체 scRNA-seq/scATAC-seq 데이터에 대해 세포 상태 해석·섭동 예측 파이프라인을 바로 적용 가능
- **원문 링크**: https://doi.org/10.1038/s41467-026-70071-5

## 2. LLM 관련 기술 (의료/생명과학 응용)

### 2-1. PULSE — A knowledge-enhanced domain-aware large language model agent for atrial fibrillation management
(멀티모달 입력, 큐레이션된 임상 지식베이스, 최적화된 프롬프트 엔지니어링, RAG를 결합한 에이전트 구조로 심방세동 환자의 자가관리를 지원하는 LLM 에이전트)

- **저널 / 발행일**: npj Digital Medicine — 2026-07-20 (DOI: 10.1038/s41746-026-03038-x, PMID 42477462, 1저자: Yijun Wang, 소속: Bengbu Medical University 제1병원·Sichuan University 화시의대). JCR 분류·IF: Q1 (Digital/Health Informatics 상위권으로 추정, 정확한 IF 수치는 미검증)
- **검색 기간 폴백**: 기본 기간(2026-11-03~11-09)·1개월·3개월 확장까지 조건을 만족하는 미보고 자료를 찾지 못해 **6개월(2026-05-09~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-07-20)
- **핵심 요약**:
  - "PULSE"(Potentiated User-friendly LLM-driven Search Engine)라는 지식 강화·도메인 특화 LLM 에이전트를 설계해, 심방세동(AF) 환자의 치료 경로 전반에서 자가관리를 지원
  - 멀티모달 입력 처리, 큐레이션된 임상 지식베이스, 최적화된 프롬프트 엔지니어링, RAG(검색증강생성)를 에이전트 구조 안에 결합
  - 다수 평가 모델 대상 실험에서 임상 정확도·내용 완전성·유용성·안전성을 통계적으로 유의하게(P<0.05) 개선했고, 공감성과 명료성도 크게 향상시키면서 간결성은 비슨한 수준으로 유지했다고 보고 (세부 평가 지표·샘플 수는 원문 전체 확인이 필요)
- **GitHub**: 이번 조사에서 PULSE 자체의 공개 코드 저장소는 확인하지 못함 — 코드 공개 여부 불확실(Nature 논문 페이지의 "Code availability" 섹션 직접 확인 필요)
- **원문 링크**: https://doi.org/10.1038/s41746-026-03038-x

### 2-2. AI4Doctor — Clinical large language model centered on electronic medical records
(전자의무기록(EMR)에서 추출한 데이터와 임상 현장 의사들의 경험적 인사이트를 지도학습 파인튜닝(SFT)에 결합하여 구축한 임상 특화 LLM)

- **저널 / 발행일**: npj Digital Medicine, Vol. 9, Article 511 — 2026-06-19 (DOI: 10.1038/s41746-026-02509-5, PMID 42321427, PMCID PMC13338390, 1저자: Yan Zhuang, 공동저자: Bo Wang, Chengliang Yin 등, Beijing Institute of Technology). JCR 분류·IF: Q1 (Digital/Health Informatics 상위권으로 추정, 정확한 IF 수치는 미검증)
- **검색 기간 폴백**: 기본 기간(2026-11-03~11-09)·1개월·3개월 확장까지 조건을 만족하는 미보고 자료를 찾지 못해 **6개월(2026-05-09~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-06-19)
- **핵심 요약**:
  - AI4Doctor라는 임상 도메인 특화 LLM을 제안하며, EMR에서 추출·정제(distill)한 데이터와 실제 진료 중인 의사들의 경험적 인사이트를 지도학습 파인튜닝(SFT) 과정에 결합
  - 일반 목적 LLM과 달리 임상 현장의 실제 의사결정 패턴을 반영하도록 설계되었다고 보고 (구체적 평가 벤치마크·비교 모델·정량적 성능 지표는 이번 조사에서 원문 전체를 확인하지 못해 추가 검증 필요)
- **GitHub**: 이번 조사에서 AI4Doctor 자체의 공개 코드 저장소는 확인하지 못함 — 코드 공개 여부 불확실
- **원문 링크**: https://doi.org/10.1038/s41746-026-02509-5

## 3. 멀티모달 AI

### 3-1. EVLF-FM — A clinical multimodal vision language foundation model with fine-grain explainability
(23개 글로벌 데이터셋·11개 영상 모달리티·130만여 샘플로 학습된 설명가능 의료 비전-언어 파운데이션 모델로, 질병 진단·시각질의응답(VQA)·의료영상 시각적 그라운딩을 지원)

- **저널 / 발행일**: Nature Medicine — 2026-10-29 (DOI: 10.1038/s41591-026-04655-5). JCR 분류·IF: Q1 최상위 (Medicine, General & Internal), IF ≈ 50~58(2차 소스 추정, 과거 리포트의 동일 저널 기준치 참고)
- **검색 기간 폴백**: 기본 기간(2026-11-03~11-09) 내에서 조건을 만족하는 미보고 자료를 찾지 못해 **1개월(2026-10-10~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-10-29)
- **핵심 요약**:
  - EVLF-FM(Explainable Vision Language Foundation Model for Medicine)이라는 멀티모달 비전-언어 파운데이션 모델을 제안, 11개 영상 모달리티에 걸친 23개 글로벌 데이터셋·총 130만여 샘플로 학습(선행 arXiv 프리프린트 2509.24231 기준, 저널 출판본에서 수치가 다를 수 있음)
  - 광범위한 질병 진단 역량과 세밀한(fine-grained) 설명가능성을 동시에 갖추도록 설계되었으며, SFT(1단계) → GRPO(검증가능 보상 기반 강화학습, 2단계) → 최종 평가의 3단계 학습 파이프라인을 채택
  - 선행 프리프린트 기준 내부 진단 검증에서 평균 정확도 0.858, F1-score 0.797을 기록했다고 보고(저널 정식본의 수치는 원문 확인 필요); 질병 진단·VQA·시각적 그라운딩 등 다중 과제를 단일 모델로 지원
- **GitHub**: https://github.com/baiyang4/EVLF (★11, 7 commits, 라이선스·최근 커밋 날짜는 확인하지 못함) — Hugging Face 가중치 다운로드 후 `inference.py`로 진단분류(cls)·VQA·그라운딩(grounding) 추론을 바로 실행 가능해, 자체 의료 영상 데이터셋에 설명가능 멀티태스크 진단 파이프라인 구축에 활용 가능
- **원문 링크**: https://doi.org/10.1038/s41591-026-04655-5
