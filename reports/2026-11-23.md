## 1. 생물정보학 (Bioinformatics)

### 1-1. SPLENDID — Incorporates continuous genetic ancestry in biobank-scale data to improve polygenic risk prediction across diverse populations
(유전적 조상(ancestry)을 이산적 그룹이 아닌 연속형 변수로 모델링하여, 혼혈·다인종 개인을 포함한 바이오뱅크 규모 데이터에서 다유전자위험점수(PRS) 예측 정확도를 높이는 방법론)

- **저널 / 발행일**: Nature Methods — 2026-09-14 온라인 발행 (DOI: 10.1038/s41592-026-03235-2). JCR 분류·IF: Q1 (Biochemical Research Methods 최상위권 저널; 2026년 공식 JCR 수치는 이번 조사에서 확인하지 못함, 미검증)
- **검색 기간 폴백**: 기본 기간(2026-11-17~11-23)·1개월 확장까지 조건을 만족하는 미보고 자료를 찾지 못해 **3개월(2026-08-23~)로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-09-14)
- **핵심 요약**:
  - 기존 PRS 방법들은 개인을 이산적 인종/조상 그룹으로 분류한 뒤 그룹별 별도 모델을 학습하는데, 조상 경계가 모호한 혼혈·다인종 개인에서는 성능이 떨어지는 한계가 있었음
  - SPLENDID는 유전적 조상을 연속형(continuum) 변수로 취급하여 조상 주성분(PC)과 변이 효과의 상호작용을 하나의 페널티 회귀 프레임워크로 함께 학습
  - 바이오뱅크 규모(수십만 명) 데이터에서 단일 모델로 다양한 인구집단에 걸친 PRS 예측 정확도를 기존 이산적 그룹별 방법 대비 향상시켰다고 보고
  - 선행 bioRxiv 프리프린트(2024.10.14.618256)가 있었으나 Nature Methods 정식 게재본을 기준으로 선정함(프리프린트 예외 규정 미적용)
- **GitHub**: https://github.com/chen-tony/SPLENDID — ★6, 포크 1, 57 커밋. R/C++/plink2 기반 CLI 도구(bigstatsr 패키지 기반 구현), 튜토리얼 포함 (라이선스는 README에 명시되지 않아 미확인) — 자체 바이오뱅크/코호트 유전형 데이터에 연속형 조상 모델링 PRS 파이프라인을 그대로 적용 가능
- **원문 링크**: https://doi.org/10.1038/s41592-026-03235-2 (선행 프리프린트: bioRxiv 2024.10.14.618256)

## 2. LLM 관련 기술 (의료/생명과학 응용)

### 2-1. BioMedAgent — Empowering AI data scientists using a multi-agent LLM framework with self-evolving capabilities for autonomous, tool-aware biomedical data analyses
(다양한 생물정보학 도구를 자율적으로 탐색·학습해 실행 가능한 워크플로로 체인화하는 자가진화형(self-evolving) LLM 멀티에이전트 프레임워크)

- **저널 / 발행일**: Nature Biomedical Engineering (DOI: 10.1038/s41551-026-01634-6). JCR 분류·IF: Q1 최상위 티어(Biomedical Engineering 분야 Top journal, IF는 2차 소스 기준 20대로 추정, 공식 수치 미확인). **정확한 온라인 발행일은 2차 소스 간 불일치**(연구기관 행사 페이지는 2026-03-16, 보도자료는 2026-06-24로 서로 다름) — 2026년 상반기로 추정되나 확정하지 못함(미검증)
- **검색 기간 폴백**: 기본 기간(2026-11-17~11-23)부터 3개월 확장까지 "GitHub 공개 논문 최우선" 조건을 만족하는 미보고 자료를 찾지 못해 **약 1년 범위까지 확장**하여 선정. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026년 상반기 추정, 정확한 일자 미확인)
- **핵심 요약**:
  - 중국과학원 컴퓨팅기술연구소(ICT CAS) 주도 연구로, 생물정보학 도구를 자율적으로 탐색·조합하여 실행 가능한 분석 워크플로를 생성하는 자가진화형 LLM 멀티에이전트 프레임워크(13개 에이전트 파이프라인)를 제안
  - 저자들이 구축한 BioMed-AQA 벤치마크(327개 생물의학 데이터 분석 과제)에서 77% 성공률을 달성
  - 외부 공개 벤치마크(BixBench)에도 일반화되어 다른 LLM 에이전트 프레임워크들을 능가하는 성능을 보임
  - 크로스-오믹스 분석, 머신러닝 모델링, 병리 이미지 분할 등 다양한 생명과학 데이터 분석 과제에 자율적으로 적용 가능함을 시연
- **GitHub**: https://github.com/BOBQWERA/BioMedAgent — README에 "LLM 기반 멀티에이전트 + 자가진화 능력 기반 자율 생물의학 분석 프레임워크"로 명시. 스타 수는 2차 소스 간 불일치로 정확한 수치 미확인(약 100★ 내외로 추정), 라이선스·최근 커밋 날짜 미확인(1차 소스 직접 접근 차단) — 자체 오믹스/임상 데이터셋에 멀티에이전트 분석 파이프라인을 그대로 적용해 전처리~모델링~해석까지 자동화 가능
- **원문 링크**: https://doi.org/10.1038/s41551-026-01634-6

## 3. 멀티모달 AI

### 3-1. An Interpretable Multimodal Deep Learning Framework Integrating MRI and Clinical Data via Bidirectional Cross-Modal Attention for Improved Cardiac Disease Detection
(심장 MRI 영상과 구조화된 임상 데이터를 양방향 교차모달 어텐션으로 결합해 해석 가능성을 확보한 심장질환 탐지 멀티모달 프레임워크)

- **저널 / 발행일**: Journal of Imaging Informatics in Medicine (Springer, 구 Journal of Digital Imaging, SIIM 공식 학술지) — 2026-11-11 온라인 발행 (DOI: 10.1007/s10278-026-02491-0). JCR 분류·IF: Radiology, Nuclear Medicine & Medical Imaging 분야 Q1로 다수 2차 소스에서 일관되게 확인됨. IF는 소스별 3.1~5.3 범위로 편차가 있어 공식 Clarivate JCR 수치는 미확인. **저자명도 2차 소스 간 일부 불일치하여 미확정**(원문 직접 확인 권장)
- **검색 기간 폴백**: 기본 기간(2026-11-17~11-23) 내에서 조건을 만족하는 미보고 자료를 찾지 못해 **1개월(2026-10-23~)로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-11-11)
- **핵심 요약**:
  - 심장 MRI 영상과 나이·검사치 등 구조화된 임상 변수를 공유 토큰 시퀀스로 인코딩한 뒤, 양방향 교차모달 어텐션(bidirectional cross-modal attention)으로 결합하는 해석 가능(interpretable) 멀티모달 프레임워크
  - 목표는 심장질환 탐지의 예측 정확도와 임상적 해석 가능성(attention 기반 설명)을 동시에 확보하는 것

- **GitHub**: 확인되지 않음. 참고로 유사 주제(MRI+EHR 기반 심장 혈류역학 예측)의 다른 연구가 https://github.com/prasunc/hemodynamics 로 공개되어 있으나 동일 논문은 아님(참고용 언급)
- **원문 링크**: https://doi.org/10.1007/s10278-026-02491-0
