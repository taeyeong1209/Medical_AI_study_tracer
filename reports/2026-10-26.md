## 1. 생물정보학 (Bioinformatics)

### 1-1. CoFormerSurv: Collaborative transformer for multi-omics survival analysis
(멀티오믹스 데이터 기반 암 생존분석을 위해 오믹스 간(inter-omics) 트랜스포머와 샘플 간(inter-sample) 그래프 트랜스포머를 순차적으로 결합한 협업형 트랜스포머 모델)

- **저널 / 발행일**: PLOS Computational Biology — 2026-01-07 (DOI: 10.1371/journal.pcbi.1013875, PMC12890224). JCR 분류·IF: Q1 (Mathematical & Computational Biology); 정확한 2025 JCR IF 수치는 2차 소스로만 확인(약 3~4대로 추정, 미검증)
- **검색 기간 폴백**: 기본 기간·1개월·3개월·6개월 확장까지 미보고 자료를 찾지 못해 **1년(2025-10-26~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-01-07)
- **핵심 요약**:
  - Gang Wen, Limin Li(저자) 개발
  - 멀티오믹스 데이터의 암 생존 예측을 위해 두 단계 트랜스포머 구조 제안: (1) 멀티헤드 셀프어텐션으로 오믹스 종류 간 상호보완 정보를 모델링하는 inter-omics transformer, (2) 융합된 멀티오믹스 샘플 그래프 위에서 샘플 간 관계·구조 정보를 반영하는 inter-sample graph transformer
  - TCGA 및 PCAWG 암 코호트에서 평가하여 단일 트랜스포머 구조 및 기존 생존분석 모델 대비 Cox 비례위험(Cox-PH) 기반 예측 성능 향상을 보고 (세부 수치는 원문 직접 열람 제한으로 확인하지 못함)
- **GitHub**: 2차 소스(뉴스 요약)에서 "저자들이 코드와 전처리 데이터를 공개했다"는 언급이 있었으나, 실제 저장소 URL은 이번 조사에서 확인하지 못함(nature.com/ncbi.nlm.nih.gov/journals.plos.org 등 1차 소스 도메인이 이번 세션 네트워크 정책상 DNS 해석 불가로 직접 열람 불가능) — 공개 여부 불확실
- **원문 링크**: https://doi.org/10.1371/journal.pcbi.1013875

## 2. LLM 관련 기술 (의료/생명과학 응용)

### 2-1. A suite of large language models for public health infoveillance (PH-LLM)
(소셜미디어 등 비정형 데이터 기반 실시간 공공보건 모니터링(infoveillance)을 위해 개발된 LLM 모델군)

- **저널 / 발행일**: npj Digital Medicine — 2026-02-23 (DOI: 10.1038/s41746-026-02435-6, Open Access). JCR 분류·IF: Q1 (Digital/Health Informatics 상위권으로 추정, 정확한 IF 수치는 미검증)
- **검색 기간 폴백**: 기본 기간부터 6개월 확장까지 미보고 자료를 찾지 못해 **1년(2025-10-26~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-02-23). 선행 medRxiv 프리프린트(2025-02)의 정식 저널 출판본이므로 프리프린트 제외 규정에 해당하지 않음
- **핵심 요약**:
  - Northwestern 대학 연구팀 개발
  - 36개 데이터셋에서 추출한 593,100개 instruction-output 쌍(96개 infoveillance 과제 + 소셜미디어 기반 QA 6종)으로 Qwen2.5 기반 모델을 QLoRA/LoRA+로 파인튜닝하여 0.5B~32B 크기의 6개 모델 공개
  - 실시간 공공보건 모니터링 과제(질병 트렌드 탐지, 공공보건 관련 소셜미디어 텍스트 분류·QA 등)에서 베이스 모델 대비 향상된 성능을 보고
- **GitHub**: 이번 조사에서 확인하지 못함(모델 가중치의 HuggingFace 공개 여부도 미검증) — 공개 여부 불확실
- **원문 링크**: https://doi.org/10.1038/s41746-026-02435-6

### 2-2. Integrating large language models for enhanced predictive analytics in healthcare (Hopkins-LLM)
(병원 전자의무기록(EHR) 구조화 데이터로 LLM을 파인튜닝해 다중 임상 예측 과제에 활용하는 프레임워크)

- **저널 / 발행일**: npj Digital Medicine — 2026-04-02 (DOI: 10.1038/s41746-026-02572-y, PMID 41927986). JCR 분류·IF: Q1 (Digital/Health Informatics 상위권으로 추정, 정확한 IF 수치는 미검증)
- **검색 기간 폴백**: 기본 기간부터 6개월 확장까지 미보고 자료를 찾지 못해 **1년(2025-10-26~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-04-02)
- **핵심 요약**:
  - Johns Hopkins Health System 연구팀 개발 (Yuli Wang, Yuwei Dai, Harrison Bai 등 참여로 확인)
  - LLaMA 기반 7B 파라미터 모델을 Johns Hopkins Health System 42,160명 환자의 구조화 EHR 데이터로 파인튜닝하여 범용 임상 예측 엔진(Hopkins-LLM)으로 구성
  - 3개 외부 병원·1,329명 환자 데이터로 외부검증을 수행해 4개 과제(30일 재입원, 90일 사망, 30일 ICU 입실, 치료 권고)에서 평균 ROC-AUC 0.84 [0.82, 0.88]를 달성, 제로샷 LLM 베이스라인 대비 유의한 향상을 보고
- **GitHub**: 확인하지 못함(병원 내부 EHR 데이터 기반 모델이라 공개 가능성이 낮은 것으로 추정) — 공개 여부 불확실
- **원문 링크**: https://doi.org/10.1038/s41746-026-02572-y

## 3. 멀티모달 AI

### 3-1. MedGemma: An open vision-language model for diverse medical applications
(Google이 공개한 Gemma 3 기반 의료 특화 비전-언어 파운데이션 모델 패밀리 및 의료 영상 인코더)

- **저널 / 발행일**: Nature Medicine — 2026-10-06 (DOI: 10.1038/s41591-026-04626-w, Open Access). JCR 분류·IF: Q1 최상위 (Medicine, General & Internal), IF ≈ 50~58(2차 소스 추정, 과거 2026-10-19 리포트 동일 저널 기준치 참고)
- **검색 기간 폴백**: 기본 기간(2026-10-20~10-26)에서 미보고 자료를 찾지 못해 **1개월(2026-09-26~)으로 확장**하여 발견. 최근 발행 자료 없어 과거 자료로 대체 (발행일: 2026-10-06)
- **핵심 요약**:
  - Google의 Andrew Sellergren, Sahar Kazemzadeh 등 연구팀이 Gemma 3 기반 의료 특화 비전-언어 모델 패밀리 MedGemma(4B/27B 멀티모달, 27B 텍스트 전용)와 400M 파라미터 의료 영상 인코더 MedSigLIP을 공개
  - 베이스 Gemma 3 대비 의료 영상 질의응답 2.6~10%, 흉부 X-ray 소견 분류 15.5~18.1%, 에이전틱 평가 10.8% 성능 향상을 보고하며, MedQA에서 86.2%로 공개 모델 중 최고 수준 달성
  - MIMIC-CXR 기반 306건 평가에서 27B 모델이 생성한 흉부 X-ray 판독문의 81%가 원본과 동등하거나 우수한 임상 결정을 내리는 것으로 평가됨
  - 제한된 학습 데이터 상황에서는 MedGemma를 파인튜닝하는 것이 베이스 Gemma 3를 직접 파인튜닝하는 것보다 효과적이라고 보고(단, 확립된 특화 의료 모델과의 직접 비교·임상 검증 데이터는 제시되지 않음)
- **GitHub**: https://github.com/google-health/medgemma (Apache-2.0, ★1.6k, 47 commits) — 사전학습 가중치(Hugging Face)와 Vertex AI 서빙/파인튜닝(SFT, LoRA, RL) 코드가 공개되어, 자체 의료 영상+텍스트 데이터셋에 파인튜닝해 영상 QA·판독문 생성 등 다양한 의료 비전-언어 과제에 바로 적용 가능
- **원문 링크**: https://doi.org/10.1038/s41591-026-04626-w
